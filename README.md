## Overview

APEX Mock Exam provides a focused online study environment for people preparing for an AI competency certification. The Korean-language test presents 30 questions in one practice session, helping learners review key material and get used to an exam-style sequence.

Once the test is submitted, the browser reports the score without delay and supplies explanations for answers marked incorrect. Question content is password-protected with AES-GCM encryption. The application can also be delivered as a web project using GitHub Pages.

## Frequently Asked Questions

### What is this practice tool designed for?

APEX Mock Exam is for learners preparing for an APEX AI competency certification exam, especially those studying with Korean-language resources.

### How large is each practice session?

A session contains 30 questions.

### Are scores calculated automatically?

Yes. Submitting the test triggers immediate grading.

### Can I review why an answer was wrong?

Yes. The application displays explanations alongside incorrect answers so they can be reviewed after grading.

### How is the question set protected?

Question data is password-protected and encrypted with AES-GCM. Check the repository configuration for the settings used during local execution or deployment.

### Where can I find the newest version?

Use the repository’s current files or the latest published build. Repository updates may include changes to both the web application and its question data.

### What should I do if the application fails to load?

Check that the published URL is accurate, that every project file was deployed, and that the browser can reach the question data. If you are running the project locally, serve the repository directory when opening the HTML file directly is unsuccessful.

### Is self-hosting supported?

Yes. The application is intended for web delivery and supports GitHub Pages. Enable Pages for the repository, then confirm that the resulting published address loads correctly.
